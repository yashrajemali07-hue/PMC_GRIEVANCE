# PMC Citizen Grievance Portal

Stack: HTML, CSS, Bootstrap 5, JavaScript, AngularJS 1.8 (frontend SPA),
Node.js + Express.js (backend), RESTful API, MongoDB with Mongoose (NoSQL).
Deployment: MongoDB Atlas + Render.

Reference: /reference/README.md describes the original Flask app (EcoTrack).
Rebuild its features as a Pune Municipal Corporation grievance portal.

Roles: citizen, admin.
Grievance categories: Garbage, Water Supply, Drainage/Sewage, Roads/Potholes,
Streetlights, Encroachment, Pollution.
Wards: use Pune ward offices (e.g. Kothrud-Bavdhan, Shivajinagar-Ghole Road,
Hadapsar-Mundhwa, Aundh-Baner, Kasba-Vishrambaugwada, Yerawada-Kalas-Dhanori).
Statuses: Submitted, In Progress, Resolved, Rejected.
Priority: High / Medium / Low.
Keep the code beginner-friendly with comments, since this is a college project.
